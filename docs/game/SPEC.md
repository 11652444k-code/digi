# 魔王の街づくり（仮）ゲーム仕様書

- 版: 0.1（骨組み）
- 日付: 2026-10-20
- 対応する要件定義: `docs/game/REQUIREMENTS.md`
- 状態: ドラフト。数値はすべて初期値であり、実プレイで調整する。

## 1. ゲームの全体像

### 1.1 コアループ

```
拾う ──→ 配属する ──→ 稼ぐ ──→ 広げる
 ▲                                │
 └──── 寿命・逃亡で席が空く ◀──────┘
```

1 周（30 秒〜1 分）の流れ:

1. 通りを歩く人物をタップして勧誘する（待機枠へ）
2. 待機枠の人物をタップし、続けて施設をタップして配属する
3. 施設が収益を生む。所持金が貯まる
4. 所持金で施設を建てる／増築する。配置を組み替えて収益を伸ばす
5. 寿命や逃亡で席が空き、1 に戻る

### 1.2 セッション設計

- 1 セッションは 3 分前後を想定。「戻ってきた → オフライン収益を受け取る → 空席を埋める → 配置を 1〜2 箇所いじる → 閉じる」
- 0 周目（チュートリアル）は 15 分で転生に到達できる長さ

### 1.3 周回（転生）による解禁

| 周回 | 解禁されるシステム | 本書での扱い |
|---|---|---|
| 0 周目 | 勧誘、配属、隣接、職業相性、建設、オフライン収益 | 本書で定義 |
| 1 周目 | 寿命 | 本書で定義 |
| 2 周目 | 勇者の襲来（取り込む） | 枠のみ（9 章） |
| 3 周目 | 災害 | 枠のみ（9 章） |
| 4 周目以降 | 職業進化、ユニーク人材 | 枠のみ（9 章） |

### 2.3 操作仕様

| 操作 | 結果 |
|---|---|
| 通りの人物をタップ | 勧誘。待機枠に空きがあれば追加。満杯なら「寮が満員だ」トースト |
| 待機枠の人物をタップ | 選択状態（配属モード）。配属可能な施設がハイライト |
| 配属モードで施設をタップ | 配属。定員超過なら拒否トースト |
| 配属モードで空きマス or 同じ人物をタップ | 選択解除 |
| 施設をタップ（通常時） | 施設詳細シートを開く |
| 建設タブで施設を選び、空きマスをタップ | 建設。所持金不足なら拒否 |
| 施設詳細シートの「移動」 → 空きマスをタップ | 施設の移設（無料、配属者ごと移動） |
| 施設詳細シートの「撤去」 | 建設費の 50% 返金。配属者は待機枠へ（溢れたら逃亡） |
| 施設詳細シートの人物をタップ | 待機枠へ戻す |

ドラッグ操作は使わない。すべてタップで完結させる。

## 3. エンティティ仕様

### 3.1 人物（Person）

| 属性 | 型 | 説明 |
|---|---|---|
| id | string | 一意 ID |
| job | enum | 職業（3.2） |
| name | string | 表示名。職業ごとの名前テーブルからランダム |
| morale | number 0〜100 | 士気。0 で逃亡 |
| age | number | 経過日数（ゲーム内日数）。1 周目から寿命判定に使う |
| lifespan | number | 寿命日数。1 周目から有効 |
| assignedTo | string or null | 配属先施設 ID |
| recruitedAt | number | 勧誘時刻（epoch ms） |

### 3.2 職業（MVP は 4 種）

| 職業 | アイコン | 出現率 | 得意施設 | 備考 |
|---|---|---|---|---|
| 村人 | 🧑‍🌾 | 50% | なし（全施設 ×1） | 序盤の主力。汎用 |
| 料理人 | 🧑‍🍳 | 20% | 飯屋 | 飯屋の士気回復量を上げる |
| 商人 | 👨‍💼 | 20% | 露店 | 露店の収益 ×3 |
| 鍛冶師 | 🧑‍🔧 | 10% | 工場 | 工場の収益 ×3。隣接工場に +20%（1 周目から） |

相性倍率: 得意 ×3.0 / 通常 ×1.0 / 不得意 ×0.5。
不得意の定義: 料理人・商人・鍛冶師が「自分の得意施設以外の収益施設」に入った場合。村人に不得意はない。寮と飯屋は収益を生まないため相性倍率の対象外。

### 3.3 施設（Facility）

| 施設 | 種別 | 建設費 | 定員 | 基礎収益/人/秒 | 解禁 |
|---|---|---|---|---|---|
| 露店 | 収益 | 100 G | 1 | 1 G | 開始時 |
| 工場 | 収益 | 600 G | 3 | 2 G | 露店 2 軒 |
| 寮 | 支援 | 250 G | 0 | 0 | 開始時 |
| 飯屋 | 支援 | 400 G | 1 | 0 | 寮 1 軒 |

- 建設費は同種 n 軒目で `基礎費 × 1.7^(n-1)`（切り上げ）
- 建設費・寿命の数値は `tests/game/balance-sim.mjs` で較正済み（bot が 20 秒ごとに確認して 0 周目の転生解禁まで約 12 分、人間なら約 15 分）
- 寮 1 軒につき収容上限 +6。初期収容上限は 6（魔王城の空き部屋という設定）
- 収容上限 = 配属中＋待機枠の合計人数の上限
- 待機枠は常に 4 スロット
- 飯屋は配属 1 人（料理人なら効果 1.5 倍）で稼働。無人だと効果なし

### 3.4 街グリッド

- 5×5 = 25 マス。MVP では全マス使用可能
- 外周 16 マスのうち上辺 5 マスは「通りに面している」扱い（Phase 2 の勇者・摘発で使う。MVP では意味を持たない）

## 4. ルール仕様

### 4.1 収益計算

施設 f の毎秒収益:

```
income(f) = Σ_{p ∈ f.workers} base(f) × jobMult(p, f) × moraleMult(p) × adjMult(f) × prestigeMult
```

| 項 | 定義 |
|---|---|
| base(f) | 施設の基礎収益/人/秒 |
| jobMult(p, f) | 相性倍率 3.0 / 1.0 / 0.5 |
| moraleMult(p) | 士気 50 以上で 1.0、50 未満で `0.5 + morale/100` |
| adjMult(f) | 隣接ボーナスの積（4.2） |
| prestigeMult | 転生ボーナス。`1 + 0.1 × 転生回数` |

総収益/秒 = 全施設の income の合計。1 秒ごとに所持金へ加算する（内部は 100ms tick、表示は 1 秒ごと更新で可）。

### 4.2 隣接ルール（MVP の 3 ルール）

隣接 = 上下左右の 4 近傍。

| ID | 条件 | 効果 | 設計意図 |
|---|---|---|---|
| A-01 | 工場の 4 近傍に寮がある | その工場の収益 ×1.3 | 「寮を工場の隣に置きたい」 |
| A-02 | 飯屋の 8 近傍（斜め含む）に配属者がいる施設 | その施設の配属者は士気が回復する（4.3） | 「飯屋も近くに置きたい」 |
| A-03 | 工場の 4 近傍に飯屋がある | その飯屋の士気回復量 ×0.5（騒音） | 「でも工場と飯屋は相性が悪い」 |

3 ルールが 1 マスを奪い合う状況を必ず作れることが条件。5×5 では工場 3〜4 軒、寮 2 軒、飯屋 1〜2 軒あたりで衝突が起きる。

ルールは配置変更の瞬間に再計算し、施設タイルに `×1.3` などのバッジで即時表示する。

### 4.3 士気

- 全配属者の士気は毎秒 `-0.2` 減少する（約 8 分で 100 → 0）
- 飯屋の効果範囲内（A-02）なら毎秒 `+0.5` 回復（料理人配属なら +0.75、A-03 適用で半減）
- 待機枠の人物は士気が変動しない
- 士気 0 で逃亡。ログに文言を出し、席を空ける
- 士気はオフライン中も計算対象（4.5）

### 4.4 寿命（1 周目から有効）

- ゲーム内 1 日 = 実時間 60 秒
- 勧誘時に寿命を `正規分布(平均 12 日, 標準偏差 4 日)` から決め、下限 6 日
- 残り 3 日で人物アイコンに 🕯 バッジ。施設詳細で残日数を確認できる
- 寿命到達で「定年退職」。送別会の費用として `50 G × 転生回数` を自動徴収（所持金が足りなければ 0）
- 退職時に空席ができ、隣接・相性の再最適化が必要になる。これが「配置を壊す仕組み」の実装

### 4.5 オフライン収益

- 復帰時、`経過秒 = min(now - lastSavedAt, 8 時間)` を計算
- 収益は閉じた時点の総収益/秒 × 経過秒 × 0.5（放置係数）。閉じている間は半分しか働かない設定
- 士気はオフライン中も減少するが、下限は 10 とし、逃亡は起こさない（戻ったら全員やる気がないが居る、という体験にする）
- 寿命はオフライン中も進む。到達した人物は復帰モーダル内で「留守中に退職した」としてまとめて通知する
- 復帰モーダルに経過時間・獲得額・退職者を表示し、閉じるまでゲームは進まない

### 4.6 転生

| 項目 | 内容 |
|---|---|
| 解禁条件（0 周目） | 累計収益 10,000 G 到達。15 分で到達する想定で数値を調整する |
| 解禁条件（n 周目） | 累計収益 `10,000 × 3^n` G |
| 失うもの | 所持金、施設、人物、グリッド配置 |
| 残るもの | 転生回数、永続ボーナス、解禁済みシステム、統計 |
| 永続ボーナス（MVP） | 全収益 +10%／転生回数（prestigeMult）。1 周目から「初期所持金 +200 G」も付与 |
| 演出 | 「街を売り払って夜逃げする」モーダル。売却額の表示（演出のみ、次周に持ち越さない） |

### 4.7 0 周目チュートリアル

4 ステップ。各ステップは該当 UI をハイライトし、完了で自動で次へ進む。

1. 「まず人手だ」通りの村人をタップして勧誘する
2. 「働いてもらおう」待機枠の村人を選び、初期配置の露店に配属する
3. 「寮を建てる」所持金 250 G 貯まったら建設タブから寮を建てる（工場の隣に置くとボーナス、と吹き出しで示す）
4. 「あとは任せた」飯屋の解禁と転生条件を伝え、チュートリアル終了

初期状態: 所持金 60 G、露店 1 軒（中央下）、工場 0 軒、通りに村人 2 人と商人 1 人。

### 4.8 人物の出現

- 通りには常時 1〜4 人。右端から出現し、約 12 秒かけて左端へ歩いて消える
- 出現間隔は `3 + random(0, 4)` 秒。収容上限が満杯のときは出現間隔を 2 倍にする
- 職業は 3.2 の出現率。ただし「得意施設が存在する職業」の出現率を 1.5 倍に補正する（置ける人が来やすい）

## 5. 文言・演出ガイド

### 5.1 トーン

- 魔王本人は真面目に悪いことをしているつもり。部下はゆるい。勇者はどこか抜けている
- 直接的に人を貶める語（奴隷、搾取など）は使わない。「福利厚生」「人事」「定年」など会社用語で言い換えると笑いになる
- 一文は短く。ログは 1 行 30 文字以内を目標

### 5.2 必須文言一覧（MVP）

| 場面 | 例 |
|---|---|
| 勧誘成功 | 「村人が『給料出るんですか？』と聞いてきた。出る、と答えておいた」 |
| 勧誘失敗（満員） | 「寮が満員だ。魔王城なのに」 |
| 配属 | 「商人を露店に配属した。本人は乗り気だ」 |
| 相性が悪い配属 | 「料理人を工場に入れた。包丁の使い方が違うと言っている」 |
| 士気低下警告 | 「工場の士気が下がっている。飯が遠い」 |
| 逃亡 | 「鍛冶師が逃げた。置き手紙には『一身上の都合』とある」 |
| 定年退職 | 「ゴブリン工員（勤続 12 日）が定年を迎えた。送別会の費用 50 G」 |
| 建設 | 「寮を建てた。魔王城より立派かもしれない」 |
| オフライン復帰 | 「あなたが寝ている間、部下たちは真面目に働いていた。意外である」 |
| 転生解禁 | 「この街はもう十分だ。売り払って次へ行こう」 |
| 転生実行 | 「夜逃げ完了。借金は次の街の自分に任せる」 |

文言は `scripts/game/data/lines.js` に場面ごとの配列で持ち、ランダムに選ぶ。各場面 3 本以上を目標にする。

### 5.3 演出

- 勧誘: 人物が待機枠へ吸い込まれるアニメーション（0.3 秒）
- 収益: 施設タイル上に `+2G` のフロートテキスト（1 秒ごとにまとめて 1 回）
- 隣接ボーナス発生: タイルの縁が一瞬光る
- 逃亡: 人物アイコンがタイルから走って画面外へ
- 既存ポートフォリオのパーティクル・グローのアニメーション資産は、転生演出に流用する

## 7. 技術仕様

### 7.1 構成

- 素の HTML / CSS / JavaScript（ES Modules、ES2020）。ビルドなし、外部ライブラリなし
- 通りの帯のみ Canvas（人物の歩行アニメーション）。グリッド、待機枠、UI は DOM
- 状態管理は単一の `state` オブジェクトと純粋関数の `reducer` 群。描画は状態からの再描画（差分更新は必要になってから）
- ゲームループは `requestAnimationFrame` で描画、`setInterval(100ms)` でシミュレーション tick。バックグラウンド時は tick を止め、復帰時にオフライン計算で埋める

### 7.3 既存ポートフォリオとの接続

- トップページの作品一覧に「魔王の街づくり（仮）」のカードを追加し、`/game/` へリンク
- 既存の `styles/main.css` は読み込まない。フォント指定（Noto Sans JP）だけ揃える
- `og:` メタは専用に設定し、スクリーンショット共有時にゲーム名が出るようにする

### 7.4 テスト方針

- `sim/` 配下はすべて DOM 非依存の純粋関数にし、`node tests/game/*.test.js` で実行できるようにする
- 検証する主な項目: 相性倍率、隣接 3 ルールの組み合わせ、士気の境界（50、0）、オフライン上限 8 時間、転生条件、セーブのマイグレーション
- UI は Playwright で「初回起動 → チュートリアル 4 ステップ完了」のスモークテストを 1 本持つ

## 9. Phase 2 以降の枠（設計メモのみ）

### 9.1 勇者の襲来（2 周目）

- 10〜15 分に 1 回、通りの上辺（通りに面したマス）から勇者が侵入する
- MVP の処遇は「取り込む」のみ。勇者は通りを歩き、カジノ（Phase 2 施設）か露店に入ると「散財して働き始める」。それ以外のマスに到達すると施設を 1 つ 60 秒停止させて帰る
- 取り込んだ勇者は「勇者」職となり、全施設 ×1.5 のユニーク人材扱い
- 上辺に露店を並べる、という配置戦略が生まれる

### 9.2 災害（3 周目）

- 地震: ランダムな 3×3 範囲の施設が 120 秒停止
- 疫病: ランダムな 1 職業の士気が一気に 30 減る
- 同種の施設を固めると被害が集中する。分散配置を促す

### 9.3 その他

- 職業進化: 勤続 10 日で上位職（商人 → 大商人など）
- ユニーク人材: 「元市長」「引退した勇者」「ドラゴン（経理）」
- シフト制: 朝・昼・夜、1 人 2 シフトまで
- 区画の不定形ピース購入
- PWA、効果音、実績
