# 魔王の街づくり（仮）要件定義書

- 版: 0.1（骨組み）
- 日付: 2026-10-20
- 状態: ドラフト。本書は大枠であり、MVP を遊んだ結果で数値・優先度を見直す前提。

---

## 1. プロジェクト概要

### 1.1 一行コンセプト

新米魔王が、迷い込んだ冒険者や村人を「福利厚生」で釣って働かせ、施設を回し、金を稼ぎ、魔王城下町を大きくしていく、配置パズル寄りの放置・経営ブラウザゲーム。

### 1.2 ねらい

| 観点 | 内容 |
|---|---|
| 体験の核 | 「あと 1 マス動かせば儲かる」の配置パズルと、「留守中に稼いでいた」の放置の心地よさ |
| トーン | 悪役だが憎めないブラックコメディ。参考: 『勇者のくせに生意気だ』の魔王像 |
| 公開先 | DIGI ポートフォリオサイト内の作品ページとして公開（GitHub Pages） |
| 期待する評価 | 「設計の面白さ」と「文言のセンス」で覚えてもらう |

### 1.3 ターゲット

- スマホで隙間時間（1 セッション 3 分前後）に触る人
- 放置ゲー・経営シムの経験がある人を主、未経験者でも 0 周目で理解できることを副目標

### 1.4 プラットフォーム

- モバイルブラウザ（iOS Safari / Android Chrome）を第一ターゲット、縦画面固定レイアウト
- PC ブラウザでも動作する（中央にスマホ幅のカラムを表示）
- PWA 対応（ホーム画面追加、オフライン起動）は Phase 2

---

## 2. スコープ

### 2.1 MVP（Phase 1）で実装するもの

1. 通りを歩く人物のタップ勧誘
2. 人物の待機枠と、施設への配属（タップ選択 → タップ配置の 2 タップ方式）
3. 5×5 グリッドへの施設配置と増築
4. 隣接ボーナス／ペナルティ（MVP では 3 ルール）
5. 職業と施設のマッチング（MVP では 4 職業）
6. 収益の自動発生、所持金、施設購入
7. オフライン収益（閉じている間の稼ぎを復帰時に提示）
8. localStorage への自動セーブ、復元
9. 0 周目の完走と 1 回目の転生（永続ボーナス 1 種）
10. 1 周目で解禁される「寿命」システム
11. 文言・演出のトーン実装（イベントログ、通知）

### 2.2 Phase 2 以降（本書では枠だけ確保）

- 2 周目: 勇者の襲来（MVP では「取り込む」の 1 択で設計）
- 3 周目: 災害（地震・疫病）
- 4 周目: 職業の進化、ユニーク人材
- シフト制（朝・昼・夜）
- PWA 化、効果音、実績
- 区画の不定形ピース購入

### 2.3 対象外（やらないと決めたこと）

- サーバー、ログイン、ランキングなどのオンライン要素
- 課金・広告
- 横画面専用レイアウト
- 「奴隷」などの直接的な語を使った表現（設定上は魔王の部下・従業員で統一）

## 3. 機能要件

| ID | 要件 | 優先度 | 受け入れ条件 |
|---|---|---|---|
| F-01 | 通りに人物が自動で歩いて現れる | 必須 | 画面内に常時 1〜4 人、職業アイコンで区別できる |
| F-02 | 人物をタップすると勧誘できる | 必須 | 待機枠に空きがあれば即座に加わり、満杯なら理由が表示される |
| F-03 | 待機枠の人物を施設に配属できる | 必須 | 待機枠タップ → 施設タップで配属。施設定員を超えない |
| F-04 | 施設をグリッドの空きマスに建設できる | 必須 | 所持金を消費して建設、建設直後から稼働 |
| F-05 | 隣接関係で収益・士気が変化する | 必須 | 配置を変えた瞬間に施設の収益表示が更新される |
| F-06 | 職業と施設の相性で収益が変化する | 必須 | 得意職 ×3、通常 ×1、不得意 ×0.5 が UI で確認できる |
| F-07 | 収益が時間経過で自動加算される | 必須 | 1 秒ごとに所持金が増える。合計収益／秒が常時表示 |
| F-08 | 士気が低下し、0 で逃亡する | 必須 | 飯屋の効果範囲外の人物は士気が減り、逃亡時にログが出る |
| F-09 | オフライン収益を復帰時に提示する | 必須 | 復帰時のモーダルに経過時間と獲得額が出る。上限 8 時間 |
| F-10 | 自動セーブ・復元 | 必須 | 30 秒ごと＋操作時に保存。リロード後に同じ状態に戻る |
| F-11 | 転生できる | 必須 | 条件達成でボタンが出る。転生後に永続ボーナスが残る |
| F-12 | 1 周目から人物に寿命がある | 必須 | 寿命到達で人物が引退し、送別ログと空席が発生する |
| F-13 | イベントログに魔王らしい文言が流れる | 必須 | 勧誘・配属・引退・逃亡・オフライン復帰に専用文言がある |
| F-14 | 0 周目チュートリアル | 必須 | 初回起動で 4 ステップのガイドが出る。15 分以内で転生に到達できる |
| F-15 | セーブデータの削除（最初から） | 推奨 | 設定から確認ダイアログ付きで削除できる |
| F-16 | 勇者の襲来 | Phase 2 | 2 周目以降、定期的に出現し、取り込むと人材になる |
| F-17 | 災害 | Phase 2 | 3 周目以降、施設 1 種がまとめて停止する |

## 4. 非機能要件

| ID | 要件 | 基準 |
|---|---|---|
| N-01 | 初回表示速度 | 4G 相当で 2 秒以内に操作可能。外部ライブラリなし、総容量 300KB 以下（画像除く） |
| N-02 | 動作フレームレート | 中位スマホで通りのアニメーションが 30fps 以上 |
| N-03 | 画面サイズ | 幅 360px〜430px を基準、320px でも崩れない。PC では最大幅 480px の中央カラム |
| N-04 | 操作性 | タップ対象は最小 44×44px。ドラッグ操作を必須にしない |
| N-05 | 可読性 | 本文 14px 以上、ダークテーマ基調、コントラスト比 4.5:1 以上 |
| N-06 | セーブ耐性 | 不正な JSON や旧バージョンのセーブでも起動できる（マイグレーション or 初期化） |
| N-07 | 依存関係 | 素の HTML / CSS / JavaScript（ES2020）。ビルド工程なし |
| N-08 | 既存サイトとの共存 | ポートフォリオの CSS と干渉しない（専用ディレクトリ、専用クラス接頭辞） |
| N-09 | アクセシビリティ | 主要ボタンに aria-label。色だけに依存しない状態表示 |
| N-10 | テスト | 収益計算・隣接判定・オフライン計算は純粋関数として分離し、ブラウザなしで検証できる |

## 5. 制約・前提

- 開発・公開は GitHub（`11652444k-code/digi`）、GitHub Pages で配信
- 画像素材は当面 SVG と絵文字で代替し、後から差し替え可能な構造にする
- 数値バランスは MVP 完成後に実プレイで調整する時間を確保する
- 配置方式は 2 タップ方式で確定（ドラッグはスマホで誤操作が多いため採用しない）

---

## 6. 成功指標（公開後に自分で確認するもの）

- 初見の人が説明なしで 0 周目を完走できる
- 1 周目で「配置を組み直す」行動が自然に発生する（寿命によって）
- 文言を見た人が 1 つ以上スクリーンショットを撮りたくなる
